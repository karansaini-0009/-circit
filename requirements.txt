# Circit — verified dependencies for macOS (Apple Silicon + Intel).
#
# Every binary package was verified against PyPI (2026-11-17) to ship real
# macOS wheels, so `pip install` works on any modern Mac:
#   PySide6 6.x          macosx_14_0_universal2 (macOS 14+; older macOS
#                        versions resolve an older 6.x automatically)
#   sounddevice 0.5.6    macosx universal2 (bundles PortAudio)
#   psutil 7.x           macosx_11_0 arm64 + x86_64
#   Pillow 13.x          macosx_11_0 arm64 + x86_64
#   ctranslate2 4.9.0    macosx_11_0 arm64 + x86_64, CPython 3.10–3.12
#   onnxruntime / av / tokenizers   macosx arm64 + x86_64
# Pure-Python packages install identically everywhere:
#   faster-whisper, pynput, keyring, google-genai, sarvamai, numpy
#
# IMPORTANT: use Python 3.11 or 3.12.  faster-whisper's binary backend
# (ctranslate2) publishes macOS wheels only up to CPython 3.12 — the
# installer (INSTALL_CIRCUIT_MAC.command) enforces this for you.
#
# Replaced relative to the Windows NOVA build (and why):
#   vosk -> faster-whisper   vosk publishes NO macOS wheels at all (its PyPI
#                            0.3.45 release ships only Linux/Windows wheels),
#                            so `pip install vosk` fails on every Mac;
#                            faster-whisper runs one multilingual model that
#                            covers English + Hindi + Hinglish offline.
#   pycaw / comtypes / pywin32 / pywinauto / echoff -> dropped: Windows-only
#                            packages; on macOS the same features run through
#                            AppleScript / IOKit / pynput instead.
